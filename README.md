# Music Streaming Database

## 1. 프로젝트 소개

음악 스트리밍 서비스를 주제로 데이터베이스를 설계하고 SQL을 활용하여 음악 이용 데이터를 분석한 프로젝트입니다.

사용자, 아티스트, 장르, 노래, 스트리밍 기록, 좋아요 데이터를 중심으로 데이터베이스를 구성하고 다양한 SQL 조회 쿼리를 작성했습니다.

## 2. 프로젝트 목표

- 음악 스트리밍 서비스의 데이터베이스 구조 이해
- ERD를 활용한 데이터베이스 모델링
- SQL을 활용한 데이터 조회 및 분석
- 테이블 간 관계와 데이터 구조 이해

## 3. 사용 기술 및 도구

| 구분 | 사용 기술 |
|---|---|
| Database | MySQL |
| Modeling Tool | MySQL Workbench |
| Query Language | SQL |
| Version Control | GitHub |

## 4. 데이터베이스 구성

총 6개의 주요 테이블을 중심으로 구성했습니다.

| 테이블명 | 설명 |
|---|---|
| user | 사용자 정보 |
| artist | 아티스트 정보 |
| genre | 음악 장르 정보 |
| song | 노래 정보 |
| streaming | 스트리밍 기록 |
| likes | 좋아요 정보 |

## 5. 주요 SQL 분석

SQL 쿼리를 활용하여 다음과 같은 데이터 분석을 진행했습니다.

- 아티스트별 스트리밍 횟수 조회
- 장르별 좋아요 데이터 분석
- 좋아요 및 스트리밍 기준 인기 음악 TOP 20 조회
- 사용자별 음악 청취 기록 조회

## 6. 프로젝트 파일

| 파일명 | 설명 |
|---|---|
| `music_streaming.mwb` | MySQL Workbench 데이터 모델 파일 |
| `music_streaming.sql` | 데이터 및 SQL 분석 쿼리 |

## 7. 프로젝트를 통해 배운 점

- 데이터베이스 모델링 및 ERD 설계 경험
- 테이블 간 관계와 데이터 구조에 대한 이해
- SQL을 활용한 데이터 조회 및 분석
- MySQL Workbench를 활용한 데이터베이스 모델 관리
